We're going to see this layer emerge in every vertical and horizontal category. And ironically, even as models improve at incredible rates, this layer still must exist - and may become even more important and useful. ## 播客

**Training Data 播客 — Box 的 Aaron Levie：在 AI 时代自我重塑与企业扩散**
1) 中文总结：Aaron Levie 的核心判断是「应用层（applied AI layer）才是价值主战场」。他认为模型能力与企业工作流之间存在巨大鸿沟，谁把这个桥搭好谁就赢；而这座桥不是单纯的技术，而是一堆运营活：连数据系统、做人在回路、处理遗留系统、做变更管理、做领域评测。他看多应用层，但也不看空模型层，历史反复证明基础设施之上总会长出同样庞大的应用层（就像 AWS 之上长出 Snowflake / Databricks）。关于 token 补贴，他认为不可持续，模型公司上市后要回归正常毛利，而 Meta、SpaceX、中国、NVIDIA 这类非经济动机玩家会把推理价格压得很低，最终价值更多流向应用层。谈到 Box 自身，他用 agentic harness 把权限、搜索、文件、embeddings 串起来，针对文档密集型场景做领域评测（complex work eval），默认模型按成本 / 精度阈值滚动更新，同时开放模型花园让用户自选。对于「工作 slop / AI 生成内容是否该被信任」，他指出社会正处在混乱过渡期：代码被视为效用（可接受 AI 生成），而方案 / 演示文稿还带着「这到底是谁的想法」的信任焦虑。关于系统记录（systems of record），他认为每家公司既要做出在自己产品上远超通用 agent 的专用 agent，又必须 headless 化、把 API 通过 MCP 暴露给 Claude / ChatGPT 等平台。最后他预测五年后企业里 90% 的 token 是用户从没发起、只看到结果的后台 agent 产生的；而 AI 在编码之外扩散更慢，是因为销售、法律等知识工作受外部因素（客户是否回复、预算、权限）制约，落地要靠耐心与领域深耕。
2) 推荐理由：Box CEO 对企业 AI 落地的一线拆解非常扎实，没有空话。尤其「模型与工作流之间的鸿沟」「token 补贴不可持续」「五年后 90% token 是后台 agent」「编码之外扩散更慢」这几个判断，对做 to-B AI、agent 基础设施、AI 投资的人都有直接参考价值。
3) 原文链接：https://www.youtube.com/playlist?list=PLOhHNjZItNnMm5tdW61JpnyxeYH5NDDx8
