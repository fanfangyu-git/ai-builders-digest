**Meta AI 高级总监 Madhu Guru（曾主导 Gemini、Veo、Nano Banana）**
1) 中文总结：Madhu 继续他的「如何做好 eval」系列第 10 篇，核心观点是：要评估过程，而不只是评估结果。就像高中数学，光答对不够，解题步骤才是关键。两条 agent 轨迹可能得出同一个答案（都是 42），但一条只做了 4 次干净的工具调用、检索对了文档，另一条做了 17 次调用、重复搜了 3 次、从 2 次错误里恢复。明显前者更好。
2) 中文全文翻译：
如何构建优秀的 eval，第 10 篇
评估步骤，而不只是结果。
就像高中数学，光得到正确答案远远不够，得到答案的过程同样关键。
两条 agent 轨迹可能给出同一个答案（42！！）。但其中一条检索了正确的来源、找到了正确的文档、做了 4 次干净的工具调用并算出结果；另一条做了 17 次调用、把同一件事搜了 3 遍、从 2 次错误里恢复，最终才抵达答案。显然哪条更好一目了然。
你需要做的是：
1/ 清晰定义你的整个工作流
2/ 定义每一步里的任务
3/ 想清楚每一步怎么度量，是拆成单独的 eval，还是作为更大 eval 的一部分
4/ 定义你的中等难度任务和困难任务，并在 eval 中体现出来
以后任何时候看 eval 结果，都先研究步骤，再看最终结果。
3) 推荐理由：这是 agent 评估里最容易踩坑、也最被忽视的一点。很多人只看「答对了没」，但真正决定可维护性和可靠性的恰恰是中间步骤。给正在搭 agent 评测体系的人一个可直接落地的框架。

**Box CEO Aaron Levie**
1) 中文总结：Aaron 本周见了几十位银行、媒体、信息服务业、保险和咨询领域的技术负责人，梳理出企业里 agent 落地的几大趋势：① 网络安全焦虑（受 OpenAI / Hugging Face 事件刺激）；② 模型混战（企业普遍同时部署多个前沿模型，但预算仍集中在少数几家，开放权重在企业里还早）；③ agent 安全与身份管理（企业希望给每个 agent 配身份并管控其行为）；④ 流程再造（真正的大收益来自改工作流本身，而非在旧流程上叠 agent）；⑤ 架构被无情调整（创新太快，没人等某个供应商做对，直接换下一个）；⑥ eval 还很早期；⑦ 遗留系统仍是最大拦路虎（数据碎片散落在为 agentic 时代之前建的老平台上）。另外他宣布 Box 与 OpenAI 加深合作，让企业内容能在 ChatGPT 里被安全调用。
2) 中文全文翻译：
（企业 agent 趋势）
再来一些路上的见闻。这周我和几十位技术负责人见了面，横跨银行、媒体、信息服务业、保险和咨询，聊的是企业里的 agent。
当下一些最大的趋势：
* 网络安全！所有人都对 AI 带来的漏洞增速感到紧张，也对 OpenAI 和 Hugging Face 事件的影响心有余悸。和硅谷相比，他们的讨论没那么「存在主义」，但对在自己的环境里具体该怎么应对，依然高度关切且务实。AI 带来了很多新发现，但也很难跟得上他们现在必须执行的所有变化。
* 模型混战仍在继续。大多数企业都在内部署多个前沿模型。很难标准化到某一个，而且不同团队和用例偏好各异。但真金白银仍集中在少数几家供应商身上。开放权重在大多数组织里规模化还处在婴儿期，往往是因为缺少本土的「前沿」开源选项。这里有很强的胃口想要更多选择，但到目前为止去处不多。
* agent 安全与身份。多少和 Hugging Face 事件相关，大家对「当 agent 试图进入它能进的每一个系统时，agent 安全和身份管理的新挑战」有了更多意识。理想情况下企业能给所有 agent 配置身份、控制它们在做什么，但当然，有时 agent 也需要完全像用户本人一样行动。
* 流程再造。大多数企业意识到，agent 最大的上行空间在于它们能改变工作流本身，从而拿到 AI 的全部收益。当企业能调整工作流、让 agent 改变工作「如何发生」，而不是仅仅把 agent 叠在现有流程上，ROI 才高得多。但大问题是：到底谁能真正推动这些改变、这件事归谁管。目前最好的经验仍是把嵌入式 FDE（前沿部署工程师）放进各业务职能里。
* 对架构的无情调整。大多数企业都有例子，过去一两年里就因为不同供应商换过好几次系统。我大概从没像现在这样频繁地听到「我们试了 X 不行，所以换成了 Y」。教训是：因为创新发生得太快，没人会守着一个供应商直到它做对，大家直接转向下一个。
* eval！对大多数企业来说，搞清自己工作流的 eval 仍非常早期。几十个客户里只有少数几个点出了这一点，但这是企业现在的一个巨大机会：好好搞清楚自己的工作到底是怎么发生的、AI 做得有多好。
* 遗留系统仍是拦路虎。一如既往，遗留系统仍是阻碍企业快速采用 AI 的主因。数据碎片散落在那些为 agentic 时代之前的世界而建的老环境里。企业花大量时间只是在清理这些老平台。
还有很多话题，但这些是当下企业里最常被挂在心上的几件。
（Box 与 OpenAI 合作）
很高兴能和 OpenAI 更深度地合作，这样你就能在 ChatGPT 里安全地调用来自 Box 的企业内容。
软件正在继续走向「无头化」（headless），我们坚信，工作的未来将是能够在任何地方处理数据、执行工作流的 AI agent。
3) 推荐理由：这是一份难得的「企业一线」拼图，把安全、模型选型、身份、流程再造、遗留系统这些真实痛点一次讲透。不管你是做 to B AI 产品还是在企业里推 agent，这份清单基本就是你的需求池。
