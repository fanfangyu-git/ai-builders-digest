1) 中文总结：Claude Cowork 桌面端内置了浏览器——任务需要用到网站时，侧边栏会打开一个浏览器，Claude 自己读页、点选、输入。你可以把 Web 子任务交给它而自己不离场：它去供应商门户拉发票、从看板取数。无扩展、无配置，且与你本机浏览器隔离（看不到你的标签页 / 书签 / 密码），可按站点把登录带过去。本周向 Pro、Max、Team 铺开，企业管理员即日起可开启。Anthropic 明确区分两种「用 Web」：内置浏览器用于「把 Web 任务交给 Claude 而你继续干活」；Claude in Chrome 用于「你正打开的页面、你已登录的账号」。
